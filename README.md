# Подслушка

Запись звонков и расшифровка на своём маке. Ничего не уходит в сеть: ни звук,
ни текст, ни метаданные. Никаких аккаунтов, подписок и ботов, которые
подсаживаются к вам в конференцию.

Работает с чем угодно, что играет звук: Zoom, Meet, Teams, Telegram, WhatsApp,
браузер. Приложению всё равно, откуда звук, — оно слушает выход системы.

## Что получается

Нажал «Запись», поговорил, нажал «Стоп». Через несколько минут в папке лежит:

```
~/Documents/Подслушка/2026-09-01_13-40-32/
├── audio.m4a        звук обеих сторон, около 27 МБ за час
├── transcript.txt   сплошной текст
├── transcript.srt   субтитры с таймкодами
├── transcript.md    расшифровка построчно
├── peaks.json       волновая форма для плеера
└── meta.json        название, заметка, язык, длительность
```

Плюс картотека в браузере: плеер с волной, транскрипт бежит синхронно с речью,
поиск по всем разговорам сразу, правка текста на месте.

## Что нужно

- macOS 13 или новее, Apple Silicon или Intel
- [Homebrew](https://brew.sh)
- Инструменты разработчика для сборки приложения: `xcode-select --install`
  (без них работают команды, но не будет панели)
- Около 2 ГБ на диске: модель распознавания весит 1,5 ГБ
- Пароль администратора один раз — для установки звукового драйвера

## Установка

```bash
git clone <адрес репозитория> podslushka
cd podslushka
./install.sh
```

Скрипт поставит ffmpeg и BlackHole, создаст окружение python с faster-whisper,
скачает модель, соберёт приложение и разложит команды. Если драйвер ставился
впервые — попросит выполнить `sudo killall coreaudiod`, чтобы система его увидела.

Дальше:

```bash
open ~/Applications/Podslushka.app
```

В меню панели — «Создать аудиоустройства». Оно соберёт `Podslushka In`
(микрофон плюс системный звук) и `Podslushka Out` (то, что вы слышите).
Перед этим в подменю выберите свой микрофон и свои наушники.

Проверить, что всё на месте:

```bash
podslushka doctor
```

## Как пользоваться

Панель висит поверх всех окон, включая полноэкранный звонок. Серая точка —
простой, красная с таймером — идёт запись, оранжевая — расшифровка.

1. В приложении звонка выберите динамик **Podslushka Out**, микрофон оставьте
   обычный. Иначе собеседник услышит эхо.
2. Предупредите собеседников, что идёт запись.
3. Нажмите «Запись» на панели. Системный выход переключится сам и вернётся
   обратно после остановки.
4. Нажмите «Стоп». Расшифровка запустится сама, папка откроется по готовности.

Без панели то же самое делает команда:

```bash
podslushka          # первый раз — старт, второй — стоп
podslushka status
podslushka-ui       # картотека в браузере
```

Хотите горячую клавишу — заведите Быструю команду с действием «Выполнить скрипт
shell» и строкой `podslushka`, повесьте на неё сочетание клавиш.

## Настройки

Всё через переменные окружения:

| Переменная | По умолчанию | Что делает |
|---|---|---|
| `PODSLUSHKA_DIR` | `~/Documents/Подслушка` | куда складывать записи |
| `PODSLUSHKA_MODEL` | `medium` | `small` быстрее, `large-v3` точнее (качает 3 ГБ) |
| `PODSLUSHKA_LANG` | авто | зафиксировать язык, например `ru` |
| `PODSLUSHKA_KEEP_WAV` | `0` | `1` — не удалять исходный WAV после сжатия |
| `PODSLUSHKA_PORT` | `8477` | порт картотеки |
| `PODSLUSHKA_HOME` | `~/.podslushka` | куда установлено |

## Сколько ждать

Модель `medium` на Apple Silicon расшифровывает в несколько раз быстрее
реального времени. Проверено на записях до 33 секунд; на часовых разговорах
мы не мерили, так что если ждать долго — переключитесь на `small`.

## Приватность и право

Звук и текст остаются на вашем диске. Единственный поход в сеть — скачивание
модели при установке.

Запись разговора с другими людьми — это сбор их персональных данных, а скрытая
запись переговоров вдобавок повод для спора. Предупреждайте собеседников
в начале звонка. В некоторых странах и компаниях запись без согласия всех
участников запрещена прямо. Ответственность за это на том, кто нажимает кнопку.

## Чего не умеет

- Не различает говорящих: кто именно сказал фразу, транскрипт не размечает.
- Не включается сама при входе в звонок. Автозапуск по появлению процесса Zoom
  ловит и просто открытое приложение, а запись там, где её не ждут, хуже,
  чем лишнее нажатие.
- Не пишет видео.
- Значок в строке меню есть, но на маках с чёлкой macOS его вытесняет, если
  места не хватает. Поэтому основной интерфейс — плавающая панель.

## Удаление

```bash
./uninstall.sh
```

Записи остаются. ffmpeg, BlackHole и звуковые устройства сносятся вручную —
скрипт напомнит как.

## Как устроено

BlackHole 2ch — виртуальная звуковая карта. Из неё и микрофона собирается
агрегатное устройство `Podslushka In`, с которого пишет ffmpeg. Всё, что вы
слышите, идёт через `Podslushka Out` — составной выход из наушников и той же
BlackHole, поэтому звук собеседника попадает и в уши, и в запись.
Расшифровывает faster-whisper локально. Картотека — сервер на стандартной
библиотеке python, слушает только 127.0.0.1.
